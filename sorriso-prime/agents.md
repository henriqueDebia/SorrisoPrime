# Sorriso Prime — Projeto

## Contexto

Este projeto é uma landing page para uma clínica odontológica fictícia chamada Sorriso Prime.

O objetivo é criar uma página que pareça um site real de uma clínica brasileira, com foco em transmitir confiança, profissionalismo e proximidade.

A página deve incentivar o visitante a entrar em contato pelo WhatsApp e agendar uma avaliação.

## Princípios de design

O projeto NÃO deve parecer uma landing page genérica gerada por IA.

Prioridades:

* aparência realista e profissional;
* design editorial e sofisticado;
* hierarquia visual clara;
* bastante atenção a espaçamento e tipografia;
* conteúdo específico e plausível;
* evitar excesso de elementos decorativos;
* evitar excesso de cards;
* evitar gradientes desnecessários;
* evitar glassmorphism;
* evitar sombras exageradas;
* evitar animações excessivas;
* evitar textos genéricos de marketing;
* evitar clichês como "revolucione", "experiência única", "solução completa" e similares;
* não utilizar emojis na interface;
* não adicionar elementos apenas para preencher espaço.

## Desenvolvimento

Use React + TypeScript + Vite.

Use Tailwind CSS para estilização.

Use Lucide React apenas quando um ícone realmente ajudar na compreensão da interface.

O código deve ser simples, legível, reutilizável e semanticamente correto.

Não adicionar bibliotecas sem necessidade.

Não criar abstrações prematuramente.

Não criar componentes excessivamente genéricos apenas para reduzir linhas de código.

## Responsividade

A experiência mobile é tão importante quanto desktop.

A interface deve ser construída pensando primeiro no conteúdo e na hierarquia, e não simplesmente reduzindo o layout desktop.

## Conteúdo

Não inventar informações médicas específicas ou alegações de resultados.

Informações fictícias devem ser coerentes entre si.

## Regra importante

Antes de implementar uma nova seção, analisar se ela realmente contribui para o objetivo da página.

Menos elementos bem executados são preferíveis a uma página visualmente carregada.
